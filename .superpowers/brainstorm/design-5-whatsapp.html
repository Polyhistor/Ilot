Design Section 5 — WhatsApp CTA & AI Integration

How the frontend hands off to WhatsApp, and how the AI layer sits behind it. Two separate concerns.

Two-Layer Architecture
LAYER 1 — Frontend (this build)
Smart wa.me Link
• Each service has a whatsapp_message field in Supabase
• CTA button constructs wa.me/[num]?text=…
• Message is pre-filled with service name + context
• Opens WhatsApp (app or web) in one tap
• Zero backend needed — pure static link
wa.me/62812345678?text=
Hi+Ilot%2C+I%27m+interested+in%3A%0A
*Investor+KITAS+2+Years*%0A
Could+you+help+me+get+started%3F
→
LAYER 2 — AI Backend (separate project)
AI-Driven WhatsApp Agent
• WhatsApp Business API (Meta) receives the message
• Webhook fires to n8n / custom API
• Claude / GPT reads message, knows service context
• Responds intelligently, qualifies the lead
• Escalates to human agent when ready
• Fully independent from the Next.js app
WA Business API
→ Webhook (n8n / Vercel fn)
→ Claude API (with service context)
→ Reply to user
→ CRM / notify team
Scope for this build: Layer 1 only. The whatsapp_message field in Supabase is the bridge — when the AI backend is ready, it reads the same pre-filled message to understand which service the user inquired about.
WhatsAppCTA Component Spec
Props: serviceName, customMessage?
Number: Stored in .env as NEXT_PUBLIC_WA_NUMBER
Default message: Falls back to "Hi Ilot, I'm interested in: [serviceName]" if no custom message
Icon: WhatsApp SVG icon inline (no extra package)
Variants: primary (gold bg), ghost (gold outline)
Opens: target="_blank" rel="noopener noreferrer"
CTA Placement
• Hero (homepage) — "Get your free quote" → gold button
• Service cards — hover reveals subtle WA icon
• Service detail page — large primary CTA above the fold
• Category pillar page — sticky bottom bar on mobile
• CTA banner section — homepage bottom CTA
• Navbar — ghost "Contact" button top-right
💬
Floating WhatsApp Button
Fixed bottom-right on all pages. Generic message: "Hi Ilot, I'd like to learn more about your services." Opens the AI agent for unstructured enquiries. Subtle entrance animation on scroll.
