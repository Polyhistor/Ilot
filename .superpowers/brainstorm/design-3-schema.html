Design Section 3 — Database Schema

3 tables. Follows the real data structure: Category → Sub-Category → Service. Supabase (Postgres).

Entity Relationship
categories
1 ──→ N
sub_categories
1 ──→ N
services
(also has direct FK to categories for fast queries)
Table: categories  ·  7 rows — one per pillar
ColumnTypeNotes
PK id uuid gen_random_uuid(), default
slug text UNIQUE e.g. visa, legal, company-setup — drives URL /visa, /legal
name text e.g. "Visa & Immigration"
tagline text Short hero description for the pillar page
icon_name text Lucide icon name for the card (e.g. "Plane", "Scale")
image_url text Background photo for the circular service card
color_accent text Hex — optional per-category tint for the pillar page header
sort_order int2 Controls order in circle (0–6)
is_active boolean Default true — hide a category without deleting
created_at timestamptz now()
Table: sub_categories  ·  e.g. "Investor KITAS", "Golden Visa", "Company Set-Up"
ColumnTypeNotes
PK id uuid gen_random_uuid()
FK category_id uuid → categories.id ON DELETE CASCADE
slug text e.g. investor-kitas, golden-visa — unique within category
name text Display name, e.g. "Investor KITAS"
sort_order int2 Display order within the category pillar page
is_active boolean Default true
Table: services  ·  Each row = one SEO page, one WhatsApp CTA
ColumnTypeNotes
PK id uuid gen_random_uuid()
FK category_id uuid → categories.id (denormalized — avoids join for listing pages)
FK sub_category_id uuid → sub_categories.id ON DELETE SET NULL
slug text UNIQUE Global unique slug — URL is /[category.slug]/[service.slug]
name text e.g. "Investor KITAS 2 Years"
description text Full description for the service detail page
target_client text e.g. "Foreign Investors"
key_deliverables text e.g. "2-Year Investor KITAS, MERP"
estimated_timeline text e.g. "6–10 Weeks"
real_time_work text Optional — internal SLA (e.g. "1 Week")
whatsapp_message text Pre-filled WA message template. Default: "Hi Ilot, I'm interested in [name]." Overridable per service.
meta_title text SEO — overrides default title if set
meta_description text SEO — overrides default if set
sort_order int2 Within sub_category
is_active boolean false = 404 / not listed
created_at / updated_at timestamptz updated_at auto-managed by trigger
Resulting SEO URLs (examples)
/visa → Visa & Immigration pillar page (all sub-cats + services)
/visa/investor-kitas-2-years → Individual service page
/visa/golden-visa-offshore-5-years → Individual service page
/legal → Legal & Contracts pillar page
/legal/pt-local-set-up → Individual service page
/legal/land-due-diligence → Individual service page
i18n note: Schema is English-only now. When Bahasa is added, a service_translations table joins on service_id + locale — no schema migration needed on the main tables.
