Design Section 1 — Project Structure

The full Next.js App Router folder layout. Reply "looks good" to move to the next section.

App Directory
src/app/
├── (marketing)/           # public pages group
│   ├── page.tsx           # homepage /
│   ├── [category]/
│   │   ├── page.tsx       # /visa, /legal …
│   │   └── [slug]/
│   │       └── page.tsx   # /visa/golden-visa-5yr
│   ├── contact/page.tsx
│   ├── legal/page.tsx
│   └── sustainability/page.tsx
├── api/
│   └── services/
│       └── route.ts       # REST API (future admin)
├── layout.tsx             # root layout + fonts
└── globals.css
Library & Data Layer
src/lib/
├── supabase/
│   ├── client.ts          # browser client
│   └── server.ts          # server component client
└── db/
    ├── categories.ts      # getCategories()
    ├── services.ts        # getServiceBySlug()
    └── types.ts           # shared TS types
Components
src/components/
├── layout/
│   ├── Navbar.tsx
│   └── Footer.tsx
├── home/
│   ├── HeroCircle.tsx     # 🔑 fan-out animation
│   ├── PartnerBar.tsx     # marquee logos
│   ├── ValueProps.tsx
│   └── ProcessSteps.tsx
├── services/
│   ├── ServiceCard.tsx
│   ├── ServiceGrid.tsx    # category pillar page
│   └── ServiceDetail.tsx  # individual service page
└── ui/
    ├── WhatsAppCTA.tsx    # pre-filled wa.me link
    └── AnimatedSection.tsx
Root Level
ilot-legal/
├── src/                   # all source code
├── public/                # static assets
├── docs/                  # seed data, specs
├── supabase/
│   ├── migrations/        # SQL schema files
│   └── seed.sql           # seed from raw JSON
├── next.config.ts
├── tailwind.config.ts
└── package.json
