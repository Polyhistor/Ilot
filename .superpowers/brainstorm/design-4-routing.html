SEO Strategy
generateStaticParams
All category + service slugs pre-rendered at build time. ISR revalidates every hour so new services from Supabase Studio go live within 60 min — no redeploy needed.
Metadata per page
generateMetadata() pulls meta_title / meta_description from Supabase. Falls back to "[name] — Ilot" format if not set.
Sitemap + robots
Auto-generated /sitemap.xml from all active services. /robots.txt allows all. Schema.org Service JSON-LD on each service page.
